# 외국인 관광지 추천

### 혼합형 설문 데이터를 기반으로 K-Prototypes 군집 분석을 수행하여 외국인 관광객의 행동 패턴을 유형화하고, 세그먼트별 마케팅 전략을 도출한 프로젝트


### ① 문제 배경 및 목표

---

외국인 관광객은 방문 목적, 소비 수준, 체류 형태가 다양하여 일관된 관광 정책 및 마케팅 전략 수립이 어렵다. 본 프로젝트는 관광객 설문 데이터를 활용하여

- 관광객 행동 패턴을 기반으로 세그먼트를 도출하고
- **고부가가치 관광객 및 핵심 타깃군을 식별**하며
- 세그먼트별 맞춤 전략 수립을 목표로 함.

### ② 분석 방법

---

**데이터**

- 외국인 관광객 조사 데이터
- 범주형 + 수치형 혼합 구조

**Feature Engineering**

- 지출경비: 이상치 처리 및 구간 구조 분석
- 체재기간 정제
- 방문지역 수, 여행패턴 변수 생성
- 동반자 / 방문횟수 / 관심계기 재구성

👉 행동 기반 변수 중심 설계

---

**군집 방법**

- 혼합형 데이터 → **K-Prototypes**
- Gamma Grid Search 수행
- k 범위: 6~10 탐색
- Elbow + 해석 가능성 기준 선택
    
    → **최종 군집 수: 11개**
    

---

**사후 분석 (Post-EDA)**

- 군집별
    - 지출 / 체류기간 분포
    - 방문지역 패턴
    - 국가 / 연령 / 동반자 구성
- UMAP 시각화로 군집 구조 확인
- 군집별 **관광 행동 특성 정성적 해석**
